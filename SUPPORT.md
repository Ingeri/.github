# Support

For questions about a project, open a discussion or issue in that project's repository and include the project name, relevant version, and what you have already tried. For issues that can be reproduced, use the bug report template.

For account-level questions, visit [@ingeri on GitHub](https://github.com/ingeri) or email [ingeritresor@gmail.com](mailto:ingeritresor@gmail.com).

Never post passwords, API keys, access tokens, private customer data, or other secrets in a public issue. To report a security vulnerability, follow [SECURITY.md](SECURITY.md).
