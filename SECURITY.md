# Security Policy

Security reports are welcome. Please do not report a suspected vulnerability in a public issue, pull request, or discussion.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** option in the affected repository's Security tab when it is available. Otherwise, email [ingeritresor@gmail.com](mailto:ingeritresor@gmail.com) with the repository name, affected versions or commits, impact, and steps to reproduce. You may encrypt sensitive details using a mutually agreed secure channel.

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability. Do not send real credentials, customer data, or unrelated personal information in a report.

## Scope

This policy covers projects maintained by Ingeri Tresor and Ingeri Tech Ltd. If a project is maintained by another party, report the issue to that project's maintainers instead.
